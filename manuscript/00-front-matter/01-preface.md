# Preface: Welcome to the Kitchen

The first time most people see PHP code, it looks like someone spilled punctuation on the screen. Angle brackets, dollar signs, and semicolons standing guard at the end of every line. It looks like a language built to keep people out.

It isn't. It's a recipe. And like any recipe, it looks intimidating right up until you cook it once.

This book teaches PHP inside one running story: **Chef Jirrum's Kitchen**, a small, slightly chaotic Filipino eatery. Every new hire starts exactly where you're starting now, knowing how to eat, but not yet how to cook. You'll be addressed throughout simply as **Cook**, the newest apprentice on the line. You'll meet Yoras, the fellow apprentice who makes every beginner mistake in the book so you don't have to learn it the hard way. You'll occasionally hear from Aling Nena ("Auntie Nena," a respectful, affectionate title for an older woman in Filipino culture). She's been cooking one way for twenty years, and is, slowly, coming around to the new way.

Why cooking, and specifically Filipino cooking? Because a good adobo and a good PHP script are built the same way. Both use a small number of core ingredients, combined in a specific order, adjusted by taste as you go, and made repeatable enough that you (or anyone else who picks up the recipe) can cook it again and get the same result. Variables are ingredients. Functions are recipe cards. A class is the recipe. An object is the actual plated dish. If you've ever adjusted a sinigang because it needed a bit more sourness, you already understand conditional logic. You just didn't call it that yet.

A few honest promises before we start cooking:

- **The metaphor never gets to lie to you.** Every technical claim in this book (what a function does, how a feature behaves, what's current in PHP today) is checked for accuracy first. The kitchen makes ideas easier to hold onto, but it never replaces the real syntax or the real rules. Every chapter gives you the correct, professional way to write the code, in plain terms, with or without the story.
- **This book teaches habits a working developer actually uses**, not shortcuts you'll have to unlearn later. From the first code example onward, you'll see input treated as untrusted until it's checked, output escaped before it's shown to a browser, and code organized in small, named, single-purpose pieces. That's not extra difficulty for beginners. It's the same habit taught early, instead of taught later as a painful correction.
- **It's written for two people at once.** One is someone who has never written a line of code. The other is a working professional who already knows another language and wants PHP specifically, cleanly, and without condescension. If a section ever feels too basic or too fast, skip ahead. Each chapter recaps what it needs.

### What you need before Chapter 1

- A computer (Windows, macOS, or Linux all work fine).
- A local PHP environment, such as XAMPP, Laragon, Herd, or PHP installed directly. This is covered in the very next chapter. Think of it as setting up your own practice kitchen before you cook for real guests.
- A text editor. VS Code is a common, free choice.
- No prior programming experience required. Curiosity and a willingness to burn a dish or two along the way are the only prerequisites.

### How this book is organized

The book follows four parts, cooked in order:

1. **The Foundation**: the core ingredients and techniques of PHP. This covers variables, types, operators, conditionals, loops, functions, arrays, and pattern matching.
2. **PHP Forms**: taking real input from real people (customers placing an order) safely and correctly.
3. **PHP Advanced**: dates, files, uploads, cookies, sessions, filtering input, and handling things going wrong.
4. **PHP OOP**: moving from cooking one dish at a time to building a proper, reusable recipe system. This covers classes, inheritance, interfaces, traits, and everything else object-oriented PHP offers.

Tie on an apron. Chef Jirrum's Kitchen is open. Let's cook.
