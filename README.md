# Fall in Love with PHP, by Jerome Edica

A PHP ebook that teaches the language through one running story: an apprenticeship in a Filipino kitchen, **Chef Jirrum's Kitchen**. Written entirely in plain English (with Filipino dish names explained on first use) so it's approachable for any reader. Built for both first-time programmers and working developers who want PHP specifically.

## Project layout

- `STYLE_GUIDE.md`: the book bible. It covers the running narrative, cast, writing-style rules, the concept-to-kitchen metaphor glossary, code standards, and the chapter template. Read this before writing or editing any chapter.
- `manuscript/00-front-matter/`: title page, preface, and table of contents.
- `manuscript/01-the-foundation/`: Part 1, complete. Chapters 1 through 21, PHP Introduction through PHP Regex.
- `manuscript/02-php-forms/`: Part 2, complete. Chapters 22 through 26, Form Handling through the complete example.
- `manuscript/03-php-advanced/`: Part 3, complete. Chapters 27 through 39, Date and Time through Exceptions.
- Remaining part (`PHP OOP`) will be added as a folder in the same pattern.
